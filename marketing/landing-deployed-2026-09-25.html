The Problem

Agents don't stop.
That is the design.

Autonomous AI agents are built to run. They spawn subagents, call APIs, write files, execute code — and they do it whether you are watching or not. The same property that makes them powerful makes them dangerous the moment your back is turned.

No cap
Claude Code, Cursor, and OpenAI Codex ship with no native budget ceiling on agent spend
No log
Most agentic frameworks produce no tamper-evident record of what ran, when, and why
No proof
EU AI Act Article 14 requires demonstrable human oversight — "we think it was fine" is not proof
"The problem is not that AI agents are unsafe. The problem is that when they are unsafe, no one can prove what happened — or stop the next one." — The founding insight, 17 April 2026.

Layer 2

KavachOS — Sanskrit for
armour. Named deliberately.

Born from the GlassWorm attack of April 2026 — a Zig-compiled dropper that targeted developer laptops via Cursor, Windsurf, and VS Code extensions. KavachOS intercepts what the agent does at the OS level before it happens.

⬡
Syscall mediation — allowlist-based. The agent cannot call what is not on the list.
⊞
Exec allowlist — only whitelisted binaries can be spawned. No surprise processes.
⊘
Egress firewall — outbound network calls require explicit permit. Exfiltration path eliminated.
▣
Sandboxed runtime — agent runs in an isolated context. Host filesystem and credentials are not reachable by default.
☰
Maritime injection signatures — 8 domain-specific patterns (MAR-001..008) for vessel-side agent deployments.

Layer 3

PRAMANA — Sanskrit for
proof of knowledge.

A cryptographic attestation protocol. Every decision AEGIS makes and every action KavachOS mediates is written into a SHA-256 chain. The chain is tamper-evident. What happened can be proven — not reconstructed from memory.

SHA-256 chain
Each audit record hashes the previous one. A single edit anywhere in the chain is immediately detectable — the hash breaks.
File-persisted
Receipts written to ~/.aegis/pramana/ — survives process restart, power loss, container teardown.
AEGIS + KavachOS alone are enforcement — they gate behavior but leave no verifiable trail. PRAMANA closes the loop: the human can override, and the override is recorded. — Protocol design invariant. DOI 10.5281/zenodo.19273330

Quick Start

Running in three minutes.
No infrastructure required.

Install both packages. Wrap your agent. The rest is automatic — caps, mediation, and attestation are on by default.

# 1. Install npm install @xshieldai/aegis @xshieldai/agent-kernel # 2. Initialise AEGIS (creates ~/.aegis/config.json) npx aegis init # 3. Set a budget cap (stops any agent session at $5) npx aegis budget set --max 5.00 --window session
// 4. Wrap any agent call — TypeScript / Node / Bun import { withKavach } from '@xshieldai/agent-kernel'; import { withAegis } from '@xshieldai/aegis'; const safeAgent = withAegis(withKavach(myAgentFn), { budgetCap: 5.00, tenant: 'my-service', });
